## Design gaps and contradictions (for the main session)

No item overrides an answered decision (D24 and D24a are final). None needs a new owner answer. The main session can veto any of them; Task 17 Step 2 records the ones that change design text.

1. **`preserve:` on a `jump_only` server is a load error (the design's own rule), and it is the only sensible reading.** A `jump_only` server is never read or written (OP8), so a rule there could never keep anything and would mislead. The design's message is used verbatim: `server "edge": jump_only has no managed file; remove preserve`. A **managed** bastion (one without `jump_only: true`) may carry `preserve:`; its kept lines never count for S5's forwarding guard or the forward probe, because both read `apply.Survivors`, which reads only the desired keys (`internal/apply/plan.go:697-704`; `forwardRefusal` starts at `:593`; phase 2 recomputes survivors from `p.Desired` at `internal/apply/exec.go:179`).
2. **A preserved line is never a held key, even when this run holds its key.** The design's Guard paragraph says so and `Survivors` already enforces it. The task text's "unless the run holds it" is read as "a held key on a preserved line is still not a survivor": the external tool may delete the line at any time. The post-write login probe offers only survivors (`internal/sshwrite/probe.go`, P11 `OfferOrder`), and D17 offers each server only its granted keys, so a held key that sits only on a preserved line is never offered (except under `--offer-all-keys`, exactly like any other unknown key). No code beyond the session-key note (gap 4).
3. **Protected and operator keys.** Owned keys are never preserved (the manifest wins), and the render writes every desired key, protected first, before the marker, so a kept line can never precede a managed line. A consequence the design does not spell out: if an operator's own key also sits on a Gitea `command=` line, that line duplicates a desired key, so apply collapses it (duplicate drift) and Gitea loses that key. The README's preserve subsection says "use a separate key for the tool's account" (Task 11 docsDelta).
4. **The session-key note.** `guardCheck`'s `removes the key this session logged in with` note (`internal/apply/plan.go:542-548`) reads `Diff.Actual`, which keeps external keys. It gains `&& !r.IsExternal(fp)` (Task 10). Only reachable with `--offer-all-keys` or an agent key that also sits on a preserved line.
5. **The schema and the data path land in one commit (lane `datapath`).** A commit where a manifest with `preserve:` loads but nothing classifies its lines would let `apply` delete exactly the lines the rule names, which breaks D24 on master (trunk-based; the owner runs from master). So the schema (Tasks 1–4), the scan, matcher, classification and render (Tasks 5–11) are one lane and one commit, and README and CLAUDE.md describe `preserve:` only from that commit. This also keeps `deadcode` green: `Config.PreserveRuleFor`'s first caller (`audit.auditOne`) lands with it. Rounds 1 and 2 of the earlier draft each held a single lane, so merging them costs no parallelism.
6. **The literal-prefix rule is `len(regexp.LiteralPrefix()) >= 4` on the unanchored pattern, nothing more.** It also subsumes two of the nine probes: `LiteralPrefix` is a prefix every match must begin with, so a pattern with a 4-byte literal prefix can never match `""` or `x` (checked with Go 1.27.3: `(abcd)?`, `(?:abcd)*` and `abcd|` all give prefix `""` and are refused by the prefix rule, not the probe). The two probes stay in `preserveProbes` because the design lists them and `FuzzLoad`'s oracle reads the list; there is no `an empty value` message (`compilePreserve` prints every probe with `%q`), and the "empty match" test row is named for the rule that refuses it. Checked at the scratch step: `.*`, `.+`, `.{10,}`, `.+@.+\..+`, `(?i)abcd` give `""`; `/.*` gives `"/"`; `abcd|abce` gives `"abc"` (RE2 factors a shared prefix out of an alternation); `gitea serv|gitea hook` gives `"gitea "` and **is accepted**; `^/usr/bin` gives `"/usr/bin"`. So the design's "A top-level alternation or `(?i)` has no literal prefix" is true for `(?i)` and for an alternation whose branches share fewer than 4 leading bytes. The load error and README say "usually". A pattern that writes `^` or `$` itself is accepted: the added `^(?:…)$` makes them redundant, not wrong.
7. **An unterminated `\Q` compiles alone but not wrapped.** `\Qgitea serv` is valid RE2 (literal to the end), but `^(?:\Qgitea serv)$` swallows `)$` as literal text and fails. The compile step reports it as `pattern does not compile` instead of panicking (`regexp.Compile`, never `MustCompile`, on the wrapped form). `FuzzLoad`'s new seed carries one.
8. **"Verbatim" comment lines lose trailing carriage returns.** `ScanFile` stores a comment line with `strings.TrimRight(line, "\r")`, and a key line uses `Key.Raw` (already whitespace-trimmed by `ParseLine`). With `TrimSuffix` (one CR, as `ParseFile` does for key lines) a line ending `\r\r` would change on every apply and never converge; `TrimRight` makes `RenderKept` then `ScanFile` a fixed point in one step, which `FuzzScanFile` pins. Every other byte of a comment line is kept.
9. **What ends a run of captured comment lines.** A blank line, a key line, an unparseable line, the managed header (any line `authkeys.ParseHeader` accepts after `TrimSpace`, not only line 1) and the marker. The header and the marker are never captured (design). An unparseable line refuses the write anyway.
10. **Text and JSON shapes the design leaves open.** Audit row: `  ~  (unknown) "git@laptop"  SHA256:…  ssh-ed25519  externally managed (preserve: command) · options: "command=\"…\",no-pty"` (the glyph painted green so color columns stay aligned; the label, options suffix and `WEAK` note are the unowned-key ones, because a kept key is not owned). The per-server counts line gains ` · N externally managed` only when N > 0. JSON `keys.external` objects are the unowned-key shape (`owner: null`, `comment`, `fingerprint`, `type`, sanitized `options`, `key_issues`) plus `rule`; the comment lines above are not in JSON. Apply prints `  note: N externally managed lines kept` (`1 externally managed line kept`) on a change **and on a converged server** (so the converged-with-only-preserved case explains itself), JSON `external_kept` on those two classes only, and the empty marker as its own row `  ~  (preserve:)  remove the empty externally-managed section` with JSON `normalize.empty_external_section`.
11. **A kept key with a weak algorithm is listed, not refused.** D29's weak-key conflict covers granted keys only; a kept key is not granted. Audit shows its `WEAK` note and `key_issues`, informational.
12. **Two or more markers.** The render writes one marker. Every extra marker in the file counts as a removed non-key line; when nothing is kept, the first marker is the empty-section row and the rest are non-key lines.
13. **`revoke --key` of a preserved (unowned) key.** D1b records a key tombstone, which beats `preserve:` from then on: audit pages REVOKED (exit 2), `--sweep` exits 2 while the line is installed, and the next `apply` on that server removes it. revoke's own apply phase reaches only `apply.Affected` servers (a rendered-bytes diff of desired keys), which this tombstone does not change. That is today's D1b behaviour for any unowned key, recorded here, no code. The E2E pins the tombstone path with a hand-written `revoked:` entry (Task 15).
14. **`authorized_keys2` is never preserved.** `preserve:` applies to the managed file only; D30 (a non-empty keys2 on a no-grant server refuses) and the move-aside on a write are unchanged.
15. **Audit scans only servers that have rules.** `auditOne` calls `ScanFile` only when `len(srv.Preserve) > 0`, so a fleet without `preserve:` pays nothing (`make bench` unchanged). `srv` is the manifest's own `config.Server` value (`audit.Run` iterates `cfg.Servers` or `opts.Servers`, which `selectServers` takes from `cfg.Servers`), so the field is always set.
16. **The design's "gitlab-style" integration line.** The E2E uses the design's own Gitea example (`command="/usr/local/bin/gitea --config=/etc/gitea/app.ini serv key-7",…` with `# gitea public key` above it, which is what Gitea writes); a GitLab-shell line has the same shape and the unit tables cover a plain `command=` rule.
17. **The most common first write reads as formatting.** When kept lines already sit in a managed file with no marker (the first `apply` after adding `preserve:` to a server), nothing else changes: Add, Remove and Rewrites are empty, `nonKeyLines` nets to 0 and `Reorder` ignores kept keys, so `normalize` sets `Whitespace` and the plan prints `(formatting) normalize: whitespace/format` while the write inserts the marker. That is today's wording for any byte drift no row explains (a header-less file whose keys match prints the same). This plan pins it as a golden row (`gitea-3` in Task 12) and documents it in README; it adds no new field. A dedicated row (`Normalize.ExternalSection`, `writing N externally managed lines under the marker`, JSON `normalize.external_section`) would be additive but is design surface the spec does not name, so it is left to the owner (see the hand-back).
18. **Guard and session-note plan goldens.** The design's Tests list names "the guard ignoring preserved" and "the session-key note skipped" among plan goldens. Both are golden rows (`locked`, `session` in Task 12) as well as unit tests (Task 10). The lockout refusal and the absent note are existing strings, so the golden pins the S6 inputs, not new text.

## How this plan is cut (read first)

### Why the lanes look the way they do

1. **Two rounds.** The design's S6 row is A `internal/config` · B `internal/authkeys/render.go`, `internal/apply` · C `internal/audit`, `internal/adopt`. B cannot run beside C: apply's tests build plans through `audit.Run` (`buildPlans`, `internal/apply/plan_test.go:33-47`), and a kept line only exists once audit classifies it. If C committed before B, apply would render without the kept lines while audit had removed them from `Diff.Unauthorized`: a write that **silently deletes** them. And if A committed alone, a manifest with `preserve:` would load while apply deleted the lines it names (gap 5). So the schema and the whole data path (scan, matcher, classification, render, apply's planner) are one lane, `datapath`, in round 1, and only what cannot change bytes on a server (apply's report and JSON, and the CLI/E2E tests) waits for round 2.
2. **`deadcode ./cmd/sshepherd` is in `make check`** (gap 5). Lane `datapath` adds every exported function with its first caller: `PreserveRuleFor` and `ScanFile` (from `auditOne`), `CommandOf` (from `PreserveRuleFor`), `RenderKept` and `ServerResult.IsExternal` (from `apply.planWrite`/`guardCheck`); Tasks 1–4 add only code reachable from `config.Parse`, so Task 4's `make check` checkpoint is green too. Round 2 adds `keptNote`, `emptySectionRow` and `keptFor`, each called by the report.
3. **`TestSchemaRoundTrip*` reflects over `config.Server`,** so the `Preserve` sample lands in Task 3 with the field, or `make check` fails.
4. **Round 2 has two lanes.** `report` owns `internal/apply/{report,json}.go` and their new goldens. `e2e` owns the hermetic CLI test, the real-sshd E2E and `scripts/integration.sh`; its assertions read only what round 1 produces (file bytes, audit's row and JSON, `converged (no changes)`, exit codes), so it does not need `report`.

### Conventions every lane follows

- Go runs under the pin: prefix every `go` command with `GOTOOLCHAIN=go1.27.3`. The rtk hook summarizes test output; use `rtk proxy go test …` when exact failure lines matter.
- A golden is rewritten only with `-update` and then read back line by line before it is accepted. Every `-update` run is followed by `git status --short -- '*testdata*'` (a new golden is untracked, so `git diff --stat` would not show it), which must list only the files the step names.
- **Failing first.** Every test is run and seen failing (build failure or assertion) before the code it tests exists; a test that pins behaviour already present says so in its step, and a build failure caused only by a sibling test does not count as seeing it fail.
- **gocyclo 15 is a production-code gate;** never `//nolint:gocyclo`. The blocks below split helpers where a function would cross it (`renderServer`, `normalize`, `renderChange`); keep the splits.
- **Run `gofmt -w` and `goimports -w` on every Go file you touch** before `make check`. Alignment in these blocks is written by hand.
- **New test variables must not shadow builtins** (revive): no `new`, `len`, `max`, `min`, `copy`, `cap`, `close`, `clear`. The blocks use `want`, `got`, `kept`, `seed`, `content`.
- **Hermetic tests own their goroutines.** Every `sshtest.Server` and agent is closed by `t.Cleanup` (the helpers do this); goleak fails the package otherwise.
- **A mutation run must finish before reporting.** Each lane's last task lists its mutants. Apply one at a time, run the named tests, record killed or survived, and revert. Report the table with the hand-back; explain any survivor (equivalent) or add the test that kills it.
- **A Fuzz target added or changed needs its seed corpus** under `<pkg>/testdata/fuzz/<Target>/` (at most 16 entries of 4 KiB or less per target). `internal/config/testdata/fuzz/FuzzLoad` is already at 16 entries: S6 adds in-code `f.Add` seeds there and no committed entry.
- **Before hand-back:** run `make check` (and `make integration` under the runner's lock when the lane says `needsIntegration`; lane `e2e` runs it for `IT_DISTRO=alpine`, the integrator for all three), then `git add -A`, unstage every path outside the lane's globs (`README.md` and `CLAUDE.md` always), and write the patch.
- **`docsDelta`** blocks are integrator-only text for `README.md`, `CLAUDE.md` Status and the spec. A lane reports them unchanged and never edits those files in its patch. README samples are copied from the goldens named in the delta, never from this plan.

func preserveFleet(t *testing.T, preserve, extra string) string {

package config

import (
	"errors"
	"fmt"
	"regexp"
	"strings"
)

// The preserve: rule kinds: what a rule's pattern is matched against (spec
// 2026-11-08 S6). They are also the rule values audit reports.
const (
	PreserveCommand = "command"
	PreserveComment = "comment"
)

// PreserveRule keeps another tool's lines in a managed file: a key line
// whose command="…" value (Command) or comment (Comment) fully matches the
// RE2 pattern is kept by apply and listed by audit (spec S6, D24, D24a).
// Exactly one field is set. omitempty keeps the generated manifest from
// writing comment: "" beside command:.
type PreserveRule struct {
	Command string `yaml:"command,omitempty"`
	Comment string `yaml:"comment,omitempty"`
}

// maxPreservePattern caps a preserve: pattern's length in bytes.
const maxPreservePattern = 512

// minPreservePrefix is the shortest literal prefix a pattern may have
// (regexp.LiteralPrefix of the unanchored pattern): ".*", ".+" and "/.*"
// would keep any line.
const minPreservePrefix = 4

// preserveProbes are texts no preserve: pattern may match: an empty value,
// common key comments and common forced commands. A pattern that matches one
// is broad enough to keep a stranger's key. "" and "x" can never match a
// pattern that passed the literal-prefix rule (every match begins with that
// prefix); they stay because the design lists them and FuzzLoad's oracle
// reads this list.
var preserveProbes = []string{
	"", "x", "user@host", "alice@laptop.local", "root@ip-10-0-0-1.ec2.internal",
	"ed25519-key-20260101", strings.Repeat("a", 64), "/bin/sh", "/usr/bin/rrsync /srv",
}

// preserveRule is one compiled rule: kind is PreserveCommand or
// PreserveComment, re the pattern anchored as ^(?:…)$.
type preserveRule struct {
	kind string
	re   *regexp.Regexp
}

// validatePreserve compiles every server's preserve: rules into c.preserve
// and refuses a rule that could keep a stranger's key. A jump_only server
// has no managed file, so a rule there is an error too.
func (c *Config) validatePreserve() []error {
	var errs []error
	c.preserve = make(map[string][]preserveRule)
	for _, s := range c.Servers {
		if len(s.Preserve) == 0 {
			continue
		}
		if s.JumpOnly {
			errs = append(errs, fmt.Errorf("server %q: jump_only has no managed file; remove preserve", s.Name))
			continue
		}
		for i, r := range s.Preserve {
			rule, err := compilePreserve(r)
			if err != nil {
				errs = append(errs, fmt.Errorf("server %q: preserve[%d]: %w", s.Name, i, err))
				continue
			}
			c.preserve[s.Name] = append(c.preserve[s.Name], rule)
		}
	}
	return errs
}

// compilePreserve checks one rule, in order: exactly one field, at most
// maxPreservePattern bytes, valid RE2 alone and anchored, a literal prefix
// of at least minPreservePrefix bytes, no probe matched. The anchored form
// is compiled with Compile, never MustCompile: an unterminated \Q compiles
// alone but swallows the closing ")$" (gap 7).
func compilePreserve(r PreserveRule) (preserveRule, error) {
	kind, pattern := PreserveCommand, r.Command
	switch {
	case (r.Command == "") == (r.Comment == ""):
		return preserveRule{}, errors.New("set exactly one of command: or comment:")
	case r.Comment != "":
		kind, pattern = PreserveComment, r.Comment
	}
	if len(pattern) > maxPreservePattern {
		return preserveRule{}, fmt.Errorf("pattern is %d bytes, at most %d", len(pattern), maxPreservePattern)
	}
	open, err := regexp.Compile(pattern)
	if err != nil {
		return preserveRule{}, fmt.Errorf("pattern does not compile: %w", err)
	}
	if prefix, _ := open.LiteralPrefix(); len(prefix) < minPreservePrefix {
		return preserveRule{}, fmt.Errorf("pattern %q must start with at least %d literal bytes; a top-level alternation or (?i) usually has none: write two rules", pattern, minPreservePrefix)
	}
	re, err := regexp.Compile(`^(?:` + pattern + `)$`)
	if err != nil {
		return preserveRule{}, fmt.Errorf("pattern does not compile: %w", err)
	}
	for _, p := range preserveProbes {
		if re.MatchString(p) {
			return preserveRule{}, fmt.Errorf("pattern %q also matches %q; make it specific to the tool's lines", pattern, p)
		}
	}
	return preserveRule{kind: kind, re: re}, nil
}

package authkeys

import "strings"

// PreserveMarker opens the externally-managed section of a managed file
// (spec 2026-11-08 S6): it follows the desired keys and precedes the lines a
// preserve: rule keeps. It is never captured as a kept line's comment.
const PreserveMarker = "# Preserved by SSHepherd (externally managed):"

// ScannedLine is one parsed key line of a file with the comment lines
// directly above it (no blank line between), which some tools use to mark
// their own lines.
type ScannedLine struct {
	Key   Key
	Line  int      // 1-based line number of the key line
	Above []string // comment lines directly above, in file order, trailing CRs trimmed
}

// ScanFile returns ParseFile's key lines, in order, each with the comment
// lines directly above it. A blank line, a key line, an unparseable line,
// the managed header (on any line) and PreserveMarker end a run of
// comments, and the header and the marker are never captured. A key line is
// parsed exactly as ParseFile does; a comment line keeps every byte but its
// trailing carriage returns, so RenderKept then ScanFile is a fixed point.
func ScanFile(data []byte) []ScannedLine {
	var out []ScannedLine
	var run []string
	for i, line := range strings.Split(string(data), "\n") {
		t := strings.TrimSpace(line)
		_, header := ParseHeader(t)
		switch {
		case t == "" || header || t == PreserveMarker:
			run = nil
		case strings.HasPrefix(t, "#"):
			run = append(run, strings.TrimRight(line, "\r"))
		default:
			if k, err := ParseLine(strings.TrimSuffix(line, "\r")); err == nil && k != nil {
				out = append(out, ScannedLine{Key: *k, Line: i + 1, Above: run})
			}
			run = nil
		}
	}
	return out
}

// CommandOf returns the value of a line's first command="…" option, unquoted
// the way sshd reads it (\" is a quote); ok is false when the line has none
// or its value is not double-quoted.
func CommandOf(opts []string) (cmd string, ok bool) {
	opt, found := FindOption(opts, "command")
	if !found {
		return "", false
	}
	_, v, _ := strings.Cut(opt, "=")
	if len(v) < 2 || v[0] != '"' || v[len(v)-1] != '"' {
		return "", false
	}
	return strings.ReplaceAll(v[1:len(v)-1], `\"`, `"`), true
}

// RenderKept renders the managed file at serial with the lines a preserve:
// rule keeps (spec 2026-11-08 S6): RenderSerial's bytes, then, only when
// kept is not empty, PreserveMarker and each kept line in order, its comment
// lines first, every line verbatim (Key.Raw). Deterministic, so a file that
// already holds this section re-renders byte-identically.
func RenderKept(entries []RenderEntry, serial uint64, kept []ScannedLine) ([]byte, error) {
	out, err := RenderSerial(entries, serial)
	if err != nil || len(kept) == 0 {
		return out, err
	}
	b := bytes.NewBuffer(out)
	b.WriteString(PreserveMarker)
	b.WriteByte('\n')
	for _, l := range kept {
		for _, c := range l.Above {
			b.WriteString(c)
			b.WriteByte('\n')
		}
		b.WriteString(l.Key.Raw)
		b.WriteByte('\n')
	}
	return b.Bytes(), nil
}

import "github.com/javadh75/SSHepherd/internal/authkeys"

// PreserveRuleFor reports the kind of the first preserve: rule of server
// that k's line matches (PreserveCommand: its dequoted command="…" value;
// PreserveComment: its comment), "" when none does. It judges one line;
// audit decides which fingerprints are kept (every line must match, and an

func (c *Config) PreserveRuleFor(server string, k authkeys.Key) string {
	for _, r := range c.preserve[server] {
		text, ok := k.Comment, true
		if r.kind == PreserveCommand {
			text, ok = authkeys.CommandOf(k.Options)
		}
		if ok && r.re.MatchString(text) {
			return r.kind
		}
	}
	return ""
}

package audit

import (
	"slices"

	"github.com/javadh75/SSHepherd/internal/authkeys"
	"github.com/javadh75/SSHepherd/internal/config"
)

// External is one line a preserve: rule keeps (spec 2026-11-08 S6): the
// line, with the comment lines directly above it, and the kind of rule it
// matched (config.PreserveCommand or config.PreserveComment).
type External struct {
	Line authkeys.ScannedLine
	Rule string
}

// externalLines returns the lines of scanned that a preserve: rule of server
// keeps, in file order. A fingerprint is kept only when every line holding
// it matches a rule: an unrestricted copy beside a restricted one would
// otherwise be kept (see ServerResult.Duplicates). An owned, revoked or
// cert-only key never is: the manifest and revocation memory win, and a
// cert-authority line would admit every certificate its CA signs.
func externalLines(cfg *config.Config, server string, scanned []authkeys.ScannedLine) []External {
	rules := make([]string, len(scanned))
	refused := make(map[string]bool)
	for i, l := range scanned {
		rules[i] = cfg.PreserveRuleFor(server, l.Key)
		if rules[i] == "" || neverKept(cfg, l.Key) {
			refused[l.Key.Fingerprint] = true
		}
	}
	var out []External
	for i, l := range scanned {
		if !refused[l.Key.Fingerprint] {
			out = append(out, External{Line: l, Rule: rules[i]})
		}
	}
	return out
}

// neverKept: a key the manifest owns, one a key tombstone names, or a line
// that accepts only certificates (spec S6 "Lines that are never preserved").
func neverKept(cfg *config.Config, k authkeys.Key) bool {
	_, owned := cfg.OwnerOf(k.Fingerprint)
	_, revoked := cfg.Revoked(k.Fingerprint)
	return owned || revoked || authkeys.CertOnly(k.Options)
}

// withoutExternal drops the kept fingerprints from the unauthorized keys and
// the duplicate findings: a kept line is neither drift nor apply's to
// remove.
func withoutExternal(unauthorized []authkeys.Key, dups []Duplicate, ext []External) ([]authkeys.Key, []Duplicate) {
	if len(ext) == 0 {
		return unauthorized, dups
	}
	kept := make(map[string]bool, len(ext))
	for _, e := range ext {
		kept[e.Line.Key.Fingerprint] = true
	}
	unauthorized = slices.DeleteFunc(unauthorized, func(k authkeys.Key) bool { return kept[k.Fingerprint] })
	dups = slices.DeleteFunc(dups, func(d Duplicate) bool { return kept[d.Key.Fingerprint] })
	return unauthorized, dups
}

// IsExternal reports whether a preserve: rule keeps fp on this server.
func (r ServerResult) IsExternal(fp string) bool {
	return slices.ContainsFunc(r.External, func(e External) bool { return e.Line.Key.Fingerprint == fp })
}

func normalize(r audit.ServerResult, entries []authkeys.RenderEntry, explained bool) Normalize {
	var n Normalize
	n.NonKeyLines, n.EmptyExternalSection = nonKeyLines(r)
	n.Reorder = matchedOrderDiffers(r, entries)

	// line (possibly with its own options) the rewrite deletes — a semantic
	// change the plan must name, never "whitespace".
	n.Duplicates, n.DuplicateOptionsDiffer = duplicateLines(r)
	if !explained && !n.Reorder && n.NonKeyLines == 0 && n.Duplicates == 0 && !n.EmptyExternalSection {

// nonKeyLines counts the comment and blank lines the rewrite removes: not
// the managed header (re-emitted), not the comment lines kept above a
// preserved line, and not the one PreserveMarker the render writes back
// while lines are kept. A marker with nothing left under it is
// emptySection instead; every further marker is a removed non-key line.
func nonKeyLines(r audit.ServerResult) (n int, emptySection bool) {
	lines := strings.Split(string(r.Content), "\n")
	if len(lines) > 0 && lines[len(lines)-1] == "" {
		lines = lines[:len(lines)-1] // a well-formed file's trailing newline, not a blank line
	}
	markers := 0
	for _, line := range lines {
		t := strings.TrimSpace(strings.TrimSuffix(line, "\r"))
		_, managed := authkeys.ParseHeader(t)
		switch {
		case managed:
		case t == authkeys.PreserveMarker:
			markers++
		case t == "" || strings.HasPrefix(t, "#"):
			n++
		}
	}
	for _, e := range r.External {
		n -= len(e.Line.Above)
	}
	if markers > 0 {
		n += markers - 1
		emptySection = len(r.External) == 0
	}
	return n, emptySection
}

// duplicateLines counts the repeated key lines the rewrite removes (same
// fingerprint as an earlier line) and whether any carried options other
// than its first copy's. A kept fingerprint is not counted: every one of
// its lines stays. Content re-parses cleanly here (parse errors were
// refused earlier).
func duplicateLines(r audit.ServerResult) (n int, optionsDiffer bool) {
	keys, _ := authkeys.ParseFile(r.Content)
	first := make(map[string]authkeys.Key, len(keys))
	for _, k := range keys {
		if r.IsExternal(k.Fingerprint) {
			continue
		}
		f, seen := first[k.Fingerprint]
		if !seen {
			first[k.Fingerprint] = k
			continue
		}
		n++
		if !slices.Equal(f.Options, k.Options) {
			optionsDiffer = true
		}
	}
	return n, optionsDiffer
}
